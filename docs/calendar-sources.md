## 日历使用说明（1.2.3）

日期格金额为当日净计薪，正数绿色、负数红色，零和未计薪灰色；未计薪显示“—”。日历以自然月排布，日薪按设置的完整工资周期计算，月度汇总与图表只合计该自然月已生效日期。入职当天及今天计入，未来不提前计入；实际收款与净计薪分别记录。日历按4/5/6行自适应，支持切月、回到今天及点日期查账。已保存请假扣款选择不随默认开关或日期资料变化。
