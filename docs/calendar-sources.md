# 日历资料来源与覆盖范围

资料核对日期：2026-10-24。农历、常用节日、二十四节气离线覆盖2020—2040年；放假调休按已核对的国务院办公厅年度通知收录2020—2026年，不能把未来传统节日日期解释为已公布的连休安排。未收录年度不推测补班。

来源：香港特别行政区政府香港天文台，公历与农历日期对照表。原始数据及其知识产权归香港特别行政区政府所有。香港天文台与DATA.GOV.HK为数据提供方，本产品并非政府或天文台出品、合作或推荐。

- [DATA.GOV.HK使用条款](https://data.gov.hk/en/terms-and-conditions)
- [香港天文台知识产权声明](https://www.hko.gov.hk/en/readme/readme.htm)
- [天文台网站非商业使用条件](https://www.hko.gov.hk/en/appweb/applink.htm)

逐年文字表用于本次非商业测试版本；需保留随包的版权及使用条件说明 dist/calendar-rights.html。商业发行应遵循相应来源的许可条件。本次未给第三方数据授予任何新的源码许可。

对照表只提取日期事实，繁体节气和“闰”转换为简体；不改变日期。以2019年末农历月份为2020年起始上下文。共7671日、504个节气日期，闰月独立保留，节日不在同名闰月重复。
