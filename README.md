# 打工人 · 工资账本（安卓版测试版）

按入职日期逐日累计固定工资，记录请假、加班、补贴、扣款、预支和实际发工资，并按主体及工资账期结算。

## 安卓版

- Android 8.0 及以上，使用系统 Android WebView，无需连接网站即可本机记账。
- 首次打开为空白账本，请在“我的”设置月薪、工作主体、入职日期和发薪周期。
- 导出通过系统文件选择器保存 CSV，不申请通讯录、定位或全盘存储权限。
- 原网页预览保留示例数据；安卓版不会把示例工资当作用户记录。

## 用户配置坚果云

在“我的 → 坚果云同步 → 连接配置”填写服务地址、账号邮箱和专用应用密码。默认地址为 https://dav.jianguoyun.com/dav/ ，默认账本路径为“打工人/工资账本.json”。应使用坚果云第三方应用密码，不使用登录密码。

点击“测试连接并保存”只验证连接并保存配置；之后点击“立即同步”才会传输账本。修改后自动同步默认关闭，用户可自行开启；仅应用打开时执行，编辑停止20秒后同步，回到前台时按间隔检查。

应用密码使用 Android Keystore 加密存于本机私有配置，不写入 GitHub、账本载荷或日志。网盘账本包含工资数据，通过 HTTPS 传输。关闭系统应用备份，卸载或清除应用数据会删除本机账本和配置，请先同步或导出。

双端同时修改时不会自动合并金额，也不会默认覆盖；用户需选择采用本机或网盘账本。上传使用 ETag / If-Match，首次创建使用 If-None-Match，拒绝覆盖已被其他设备更新的版本。服务器不提供强 ETag 时拒绝覆盖已有账本。远端异常、认证失败、超时或请求受限均保留本机数据。

本机清理会暂停自动同步；之后手动同步可能把本次删除传到网盘。同步前被替换的账本快照保留于本机 previous-book 存储键，适合开发排障；CSV 不能直接作为应用的完整恢复文件。

坚果云官方配置说明：https://help.jianguoyun.com/?p=2064

## 验证与构建

网页逻辑无外部运行依赖，使用 Node.js 22 及以上：

```
npm run check
npm run test:ui
npm run dev
```

预览构建输出为 preview/dagongren-preview.html。preview 为生成目录，不提交仓库。

安卓构建需要 JDK 17、Gradle 8.11.1、Android SDK 35。Android Gradle Plugin 固定为 8.10.1：

```
gradle -p android testDebugUnitTest lintDebug assembleDebug
gradle -p android connectedDebugAndroidTest
```

GitHub Actions 在拉取请求中执行网页测试、模拟交互、安卓单元测试、静态检查、APK 构建和 Android 15 模拟器运行测试。通过构建生成的测试安装包位于工作流产物 dagongren-0.9.0-test-apk 中，并附 SHA-256 校验值。

这是可安装的调试签名测试版，未配置商店发行签名。不同全新编译环境的调试签名可能不同，不能保证覆盖安装；正式分发需另行配置固定签名。

## 边界

- 内置节假日表仅含2026年，后续年份需更新。
- 工资规则为应用内约定的自然日累计口径，不自动计算个税或社保，也不替代劳动合同或法定工资核算。
- 真实坚果云账号的可用权限、额度和连接情况，需要用户填写后由“测试连接”验证。没有使用用户真实账号做外部联调。
- 旧网页中的同步演示逻辑仅保留在浏览器预览与兼容性测试中；安卓版使用原生 WebDAV。
